Three-Pillar Architecture

Tier 1 • Synchronous Kernel Wall

Fail-Closed eBPF LSM

lsm/file_open resolves paths via bpf_d_path into per-CPU scratch memory before reserving ringbuf space — returning -EPERM before a single byte is read, even under a deliberate ringbuf saturation flood. Automatic fallback to fentry, syscall tracepoints, and procfs.

Pillar 2 • Continuous Remediation

CVE/KEV Scanner & Self-Healer

Pure-Go dpkg/apk inventory, deleted .so detection in /proc/*/maps, and baseline sysctl/0600 drift checks against opt-in OSV.dev + CISA KEV or airgapped JSON bundles. Security-only apt-get upgrades with zero shell execution.

Pillar 3 • 0-Day Containment

TTL-Bounded Virtual Patcher

Synthesizes temporary declarative containment rules + lsm/bprm_check_security blocking for unpatched 0-days under live (dev, ino) anti-lockout indices, runtime vpExeGuard, O_PATH|O_NOFOLLOW, and ext4/xfs/btrfs i_generation checks.

Layer 2 • Refusal-Resistant Triage

Uncensored Local AI Guardian

Supports Ollama, llama.cpp, Venice.ai, and OpenRouter with a guided 4-point refusal test wizard so real threat telemetry never triggers safety refusals. Hard invariant: AI can explain or escalate, never downgrade verdicts.

Immutable Appliance

Read-Only SquashFS ISO

Hybrid BIOS + UEFI Debian Bookworm ISO booted with lsm=lockdown,yama,integrity,apparmor,bpf, lockdown=integrity, default-deny nftables, locked accounts, no sshd, and Ed25519 A/B manifest verification tooling.

Tamper-Evident Control Plane

Root-Only API & Hash-Chained Audit

Loopback-only admin API (127.0.0.1:9443) with 0600 root bearer token, self-contained Web UI (zero external CDNs), and SHA-256 hash-chained audit.jsonl verified via ringwallctl verify-log.

Quick Start (Any Linux Host)

VERSION=v0.2.0
BASE="https://github.com/samyxo-bv/ringwall/releases/download/${VERSION}"
curl -fsSLO "${BASE}/ringwall-${VERSION}-linux-amd64.tar.gz"
curl -fsSLO "${BASE}/SHA256SUMS.txt"
grep "linux-amd64.tar.gz" SHA256SUMS.txt | sha256sum -c -

mkdir -p ringwall-install && tar -xzf "ringwall-${VERSION}-linux-amd64.tar.gz" -C ringwall-install
cd ringwall-install && sudo ./packaging/install.sh

sudo ringwallctl setup        # Guided AI + mode wizard with live 4-point refusal test
sudo ringwallctl scan         # Live CVE/KEV, stale-library & kernel drift scan
sudo ringwallctl simulate     # 5 safe built-in attack scenarios
sudo ringwallctl verify-log   # Verify SHA-256 audit hash chain

Live Attack Verification (Not Just Unit Tests)

Every commit and release passes Go -race tests across all 12 packages, live Ubuntu host LSM proofs (ssh -F & rogue SSH_AUTH_SOCK ssh-add blocked with -EPERM, ext4 FS_IOC_GETVERSION + bprm block/revoke, opt-in ssh-keygen positive control, LD_PRELOAD main/pthread/fork blocked at ld.so map time, pre-exec PTRACE_TRACEME blocked), AND 16 live attack assertions inside the booted QEMU ISO (hardlinks, /usr/../home, //home, /tmp/ssh spoof, symlinks, io_uring, userns, and UDP ringbuf saturation flood).
